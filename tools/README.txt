Dossier tools/ — binaires locaux (non versionnés sur GitHub)
============================================================

Ce dossier est rempli automatiquement par les scripts d'installation :

  Windows : install.bat  →  tools\ffmpeg.exe + tools\ffprobe.exe
  Linux   : ./install.sh →  tools/ffmpeg + tools/ffprobe

Ne commitez PAS ces fichiers (trop volumineux) : voir .gitignore.

Python (Windows) n'est PAS téléchargé ici.
Téléchargez le Python Install Manager depuis :
  https://www.python.org/ftp/python/pymanager/python-manager-26.3.msix

Voir DOCUMENTATION.md pour le détail.
